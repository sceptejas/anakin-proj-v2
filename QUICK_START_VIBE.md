# 🚀 Quick Start - Vibe Matcher

## 1. Get Gemini API Key (2 minutes)

1. Go to: **https://aistudio.google.com/apikey**
2. Sign in with Google
3. Click "Create API Key"
4. Copy the key

## 2. Add to .env.local

Open `ex-ray-vision/.env.local`:

```bash
NEXT_PUBLIC_GEMINI_API_KEY=paste_your_key_here
```

## 3. Restart Server

```bash
cd ex-ray-vision
npm run dev
```

## 4. Test It

Open: **http://localhost:3000**

Try this:
```
LinkedIn: satyanadella
Reddit: u/thisisbillgates  
Twitter: @elonmusk
```

Click **[ ANALYZE VIBE ]**

## 5. Watch Console

Press **F12** to see:
```

✅ [GEMINI PARSED]
```
